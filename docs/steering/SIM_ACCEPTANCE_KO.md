## 2. A17 기준

시간은 SIM 시간이다. T1에서는 결정적이다.

- STOP 요청 수신 → `STOP` 바이트 송신 ≤ 20 ms(브리지 1틱).
- MCU `STOP` 파싱 → 구동 출력 0 ≤ 1 서보 틱.
- STOP 확인(상태 줄) ≤ 2 상태 주기. 확인 실패 대본에서는 50 ms 간격 재전송 ≤ 5회 뒤 `stop_unconfirmed` 래치.
- `C` TTL 만료 → 구동 0 ≤ ttl + 1틱.
- 링크 watchdog → 구동 0 ≤ `watchdog_ms` + 1틱, DISARMED, 래치.
- 결함 정지 → 조향 출력 0 ≤ 1틱. 유지 정지에서 조향 유지 오차 ≤ max(1°, 2·서보 데드밴드).
- 자동 재출발 0. 래치는 운영자 재무장으로만 풀린다.
- 끊김 동안 옆 벗어남:
  - 정합성 기준: SIM 결과가 해석값(유지 조향각, 속도, 정지 모드로 계산한 호)과 ±10 % 또는 ±0.01 m 안.
  - 설계 목표(보고): 기본 프로필, \|δ\| ≤ 5°, 0.4 m/s에서 ≤ 0.05 m.
  - 참고 계산[추정]: 0.4 m/s, brake(시작 0.10 s, 2.0 m/s²)에서 정지까지 시간이 V2식 watchdog 2.0 s면 옆 벗어남은 δ 5°에서 약 0.045 m, 20°에서 약 0.18 m다. V3 TTL 0.3 s면 5°에서 약 0.002 m, 20°에서 약 0.010 m다.
- 09-19 제어 설계의 필수 장애 시험을 대본으로 둔다: 두 화면과 CLI 동시 조종, 누른 채 통신 끊김, 대시보드·브리지 강제 종료, USB 분리·재연결(pty 다시 열기), MCU 리셋, 반쪽 프레임, CRC·범위 오류, 상태 줄 유실, STOP 직후 늦게 온 drive, 시스템 시각 변경(단조 시계 유지).

## 3. 개정

### 개정 1 — A4(F) release 중앙값의 표본 (2026-11-09, 다음 A4(F) 판정 전)

- 등록 문구는 중앙값을 낼 표본을 정하지 않았다.
- P2 run1의 하네스 표본(창 안 정지 약 100개)은 field1010 곡선에서 0.5575 m로 창 밖이었다. 이 실패 기록은 그대로 둔다. run2 표본은 두 곡선 모두 창 안이었다.
- 진단 실행(판정 아님, seed 4000개)에서 모델 중앙값은 field1010 0.5648 m, P_fit1003 0.5812 m로 둘 다 창 안이었다. 그러나 정지 약 100개 표본을 다시 뽑으면 field1010 중앙값이 창 밖으로 나가는 비율이 24.7 %였다. 이 크기의 표본으로는 판정이 seed에 좌우된다.
- 앞으로의 판정 표본: 곡선마다 release 장면을 아직 쓰지 않은 seed 10000~13999(4000개)로 돌린다. stream key는 `a4_release_<곡선>`이고 실행 방식 이름은 넣지 않는다. 정지 직전 속도 0.90~0.95 m/s 창 안의 정지 전부(약 900개)로 중앙값을 낸다.
- 합격 창(0.56~0.60 m)은 바꾸지 않는다.

### 개정 2 — G-SIM 측정 정의 (2026-11-09, P5 첫 측정에서 정한 것을 이후 G-SIM 측정에 쓴다)

- 등록 기준에 숫자가 없는 곳을 P5 측정 담당이 합격 실행 전에 코드로 정했다(`GZ_MODEL_KO.md` 6절). P6a·P7과 프로필을 바꾼 뒤의 G-SIM 재측정도 같은 정의를 쓴다.
- 회전반경은 뒤차축 중심 궤적에 원을 맞춘다(출발 뒤 8~48 s). 출발 방향 무관은 출발 방향 0°, 90°, 113.33°의 반경이 평균의 ±1 % 안이다.
- A4(G) duty 3점은 40·70·88 %이고 기준 속도는 주 곡선이다. 정지 거리는 사건 시각부터 차체 속도가 처음 0.005 m/s 아래로 내려갈 때까지의 경로 길이다.
- A21(G) 수치 허용은 1e-6 rad다.
- A25 관절 속도 튐 한계는 조향 관절 1.5 × 공유 모델의 가장 큰 조향 속도, 구동 관절 1.25 × ω0(기구학 모드는 1.25 × 가장 큰 명령 속도)다. 조향 한계는 첫 짧은 시험(12 s) 뒤 1.25배에서 1.5배로 넓혔다. 1.25배로도 모든 측정이 통과했다.
- A10은 240 s를 돌리고 앞 20 s를 빼고 5 s 창의 Δsim/Δreal 중앙값을 쓴다. 렌더링 경로(D3D12 또는 소프트웨어)를 함께 적는다.
- A25는 lockstep에서 그 스텝 끝 시각의 공유 모델 각을 목표로 본다. 다른 프로세스에서 보내는 경로(P6a 에뮬레이터)는 따로 잰다.

### 개정 3 — A12 ① 맞춤 형식 (2026-11-09, A12 첫 측정 전)

- P5 측정에서 G-SIM 힘 모드 곡률은 속도와 무관하고 δ에 따라 달랐다(a = 0.5에서 δ 5/10/20°의 η 0.987 / 0.975 / 0.950). 등록 형식 κ = tan δ / (L_eff + K·v²)은 δ 의존을 담지 못해 K가 속도 항에 섞였다(K −0.077, 곡률 잔차 최대 2.2 %).
- A12 ①에서 δ별 η(δ)(K ≈ 0) 형식을 쓸 수 있다. 등록 형식으로 맞춘 결과도 함께 보고한다.
- 판정 수치(위치 차 ≤ max(0.10 m, 1.5 × A1 잔차로 예측한 차이), 방향 차 ≤ max(2°, 1.5 × 예측))는 바꾸지 않는다. 맞춤 잔차가 작아지면 예측 차이도 작아지므로 기준은 느슨해지지 않는다.

### 개정 4 — A17의 P3 호스트 시간 (2026-11-09, 기준 변경 아님)

- P3에서 가짜 MCU로 잰 호스트 쪽 시간(STOP 송신, 확인, 재전송, 래치, TTL)은 호스트 논리 확인이다. A17(F)·A17(G) 판정은 P4·P6a에서 한다.

### 개정 5 — 프로필 v0.1과 G-SIM 바퀴 충돌 형상 (2026-11-09, 기준 변경 아님)
