주행 제어

실차 LiDAR·IMU 위치 추정과 제동 검증 후 시작 가능 · 속도 설정은 저장됩니다.

현장 시험 준비 (점검 자료 수신 대기)

자료 검토와 실차 교정 상태입니다. 모든 항목 확인 후에도 자동 구동 연결·검증은 별도입니다.

    조종 활성화를 켠 뒤 WASD 키나 방향 버튼으로 주행합니다. 키를 놓으면 감속합니다.

    STOP, Esc, 창 이탈은 즉시 정지와 조종 해제입니다. 대각선 키는 주행 중 회전이며 속도 100%에서는 회전이 제한됩니다.
